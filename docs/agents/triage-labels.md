# Triage Labels

The Matt Pocock skills speak in terms of five canonical triage roles. This private fork uses the default label strings.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the corresponding label string from this table.

If the repository later adopts another label vocabulary, update this file rather than changing the skills or root `AGENTS.md`.
